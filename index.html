Manifiesto

La forma sigue a la pregunta

Este espacio no busca sonar definitivo. Busca sostener la duda con claridad, ritmo y una voz que no se esconda detrás de palabras vacías.

Cada entrada puede partir de una intuición, una cita, una contradicción o una escena cotidiana. La idea es convertir lo disperso en una pieza que se lea con calma.

Tono sugerido

La filosofía empieza cuando una respuesta deja de cerrar el problema y la pregunta se vuelve más honesta que la conclusión.

Plantilla de una entrada

  1. Pregunta inicial: qué problema abre el texto.
  2. Tesis breve: qué postura se sostiene.
  3. Desarrollo: un ejemplo, una tensión o una objeción.
  4. Cierre: una frase que deje la idea resonando.
